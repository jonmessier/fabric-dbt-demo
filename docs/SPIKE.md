## Findings and follow-ups

- **Planted data problems behave as designed on Fabric.** The nightly build ends with 2 errors: yield > 100%, which also skips the 7 `fct_batch` nodes, and the missing ND excise rate in gold. It also gives 6 warnings: late distributor, 37 invoice lines without a shipment, 14 unmapped Northland SKUs, an unknown state spelling, a missing excise rate in silver, and 3 unmapped SKU groups in gold. `.\tasks.ps1 build` therefore exits 1 in the "act 1" state.
- **A fresh environment needs the incremental bootstrap**, also in the Fabric dbt job (phase 6/7). The job runs a single command, so `deploy.py` or the pipeline must run `dbt run -s config.materialized:incremental --empty` once before the first build in Test/Prod.
- **`--empty` and aliased refs:** `dbt run --empty` wraps each ref as `(...) AS _dbt_limit_subq`, so `{{ ref('x') }} as y` breaks. Fixed in `fct_sales_line`. `fct_channel_inventory_monthly` and `tests/singular/assert_excise_rate_for_every_sales_state.sql` still alias refs directly. Change them to import CTEs before using `dbt build --empty` (for example in CI).
- **Python:** the job runtime is Python 3.12; local stays 3.11 (CLAUDE.md). No difference observed.
- **Proposed DESIGN.md updates** (not made here, because DESIGN.md has uncommitted edits in the working tree): §7 venv line → dbt-core 1.11 / dbt-fabric 1.10.0 + ODBC Driver 18; §10 last bullet (mssql-python) → answered: not on the runtime version; §4 orchestration → add the SQL endpoint refresh step, and note freshness can't run as a dbt job operation; §5 macros → add `drop_dbt_tmp_relations.sql`.
- **Fabric items created in `LPB-Data-Dev`:** `lh_bronze`, `wh_analytics` (+ schemas), `nb_ingest_bronze`, `dbt_lpb` (definition from the failed attempts; reconfigure in the UI). The spike copy of the dbt project is in `lh_bronze/Files/dbt/lpb`. Nothing was created outside `LPB-Data-Dev`.
- **IDE:** the VS Code YAML schema flags `data_tests:` and `unit_tests:` as "not allowed". The schema is outdated; dbt parses these files without warnings.
